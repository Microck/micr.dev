ARCHITECTURE:
-------------
The implementation uses a multi-layered architecture:

1. Root Container (min-h-screen, relative position)
   └── AuraBackground (fixed position, z-index: default)
   └── SmoothScroll Wrapper (#smooth-wrapper)
       └── Scroll Content (#smooth-content)
           └── App Content (Header, Main, etc.)
   └── Fixed UI Elements (outside scroll content)
       ├── ThemeToggle (fixed bottom-right, z-index: 101)
       ├── MobilePopup (fixed overlay, z-index: 50)
       └── TargetCursor (fixed, z-index: 9999)

This structure ensures:
- Background animations remain fixed
- Content scrolls smoothly
- UI controls stay accessible during scroll
- No z-index conflicts or transform issues

INITIALIZATION FLOW:
--------------------
1. Component mounts
2. Check prefers-reduced-motion → exit if true
3. Check viewport width → exit if mobile
4. Load ScrollSmoother script from CDN
5. Wait for script load completion
6. Check again for reduced-motion and desktop
7. Detect touch device for adjusted settings
8. Create ScrollSmoother instance with config
9. Attach resize listener for dynamic disable
10. Setup hash change listener for scroll sync

CLEANUP FLOW:
-------------
1. Component unmounts
2. Remove resize event listener
3. Kill ScrollSmoother instance
4. Set instance ref to null
5. Kill all ScrollTrigger instances
6. Remove hash change event listener
7. Remove script tag from DOM

CONFIGURATION:
--------------
ScrollSmoother.create() is called with:
- wrapper: ref to #smooth-wrapper div
- content: ref to #smooth-content div
- smooth: 1.5 (desktop) or 0.5 (touch devices)
- effects: true (enable data-speed parallax)
- smoothTouch: 0.1 (touch) or false (desktop)
- normalizeScroll: false (preserve native behavior)
- ignoreMobileResize: true (prevent layout shifts)

PERFORMANCE CONSIDERATIONS:
---------------------------
- Script loads asynchronously (non-blocking)
- Component renders immediately (no layout shift)
- Fallback to native scroll if loading fails
- will-change: transform hint for GPU acceleration
- requestAnimationFrame used by ScrollSmoother internally
- Mobile devices bypass entirely (native scroll)
- Reduced motion users bypass entirely (accessibility)
