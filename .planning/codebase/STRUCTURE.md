# Codebase Structure

**Analysis Date:** 2026-01-26

## Directory Layout

```
root/
├── anonq/              # Next.js Application (Anonymous Q&A)
├── microkeebs/         # Vite React Application (Keyboard Gallery)
├── netlify/            # Netlify Configuration
│   └── functions/      # Serverless Backend Functions
├── quarzite/           # Static Site (Win98 Style Character Page)
├── resume/             # Static Site (3D Portfolio)
├── about/              # Static Site (Personal Info)
├── tree/               # Static Site (Link Tree)
├── netlify.toml        # Global Deployment Config
└── package-lock.json   # Root lockfile (mostly empty)
```

## Directory Purposes

**anonq/**
- Purpose: Anonymous Q&A platform
- Stack: Next.js 15, Supabase, Auth0
- Key files: `app/` (routes), `package.json`

**microkeebs/**
- Purpose: Mechanical keyboard showcase
- Stack: Vite, React 19, Three.js
- Key files: `src/` (source), `index.html`, `vite.config.ts`

**netlify/functions/**
- Purpose: Shared backend logic and admin tools
- Stack: TypeScript, Node.js
- Key files: `admin-auth.ts`, `lib/` (shared helpers), `package.json`

**quarzite/**
- Purpose: Creative coding / OC showcase
- Stack: HTML, CSS, Vanilla JS
- Key files: `index.html`, `css/`, `js/`

**resume/**
- Purpose: Main interactive portfolio (Spline 3D)
- Stack: HTML, Spline Runtime
- Key files: `index.html`, `scene.splinecode`

## Key File Locations

**Entry Points:**
- Router: `netlify.toml`
- AnonQ: `anonq/app/layout.tsx`
- Microkeebs: `microkeebs/src/main.tsx`

**Configuration:**
- Deployment: `netlify.toml`
- AnonQ Env: `anonq/.env` (implied)
- Microkeebs Env: `microkeebs/.env` (implied)

**Core Logic:**
- Admin API: `netlify/functions/*.ts`
- Auth Helpers: `netlify/functions/lib/auth.ts`

## Naming Conventions

**Directories:**
- Top-level projects: `kebab-case` (e.g., `microkeebs`, `anonq`)
- Source folders: `src`, `app`, `lib` (standard)

**Files:**
- TypeScript: `kebab-case.ts` (e.g., `admin-auth.ts`)
- React Components: `PascalCase.tsx` (implied standard)

## Where to Add New Code

**New Full-Stack App:**
- Create new directory in root (e.g., `new-app/`)
- Add build step to `netlify.toml`
- Add redirect rule in `netlify.toml`

**New API Endpoint:**
- Create `netlify/functions/new-function.ts`
- Deploy (Netlify auto-detects functions)

**New Static Page:**
- Create new directory (e.g., `landing/`)
- Add `index.html`
- (Optional) Add redirect in `netlify.toml` if custom URL needed

## Special Directories

**dist/**
- Purpose: Build output for Vite apps (`microkeebs/dist`)
- Source: Generated by `npm run build`
- Committed: No (should be gitignored)

**.next/**
- Purpose: Build output for Next.js (`anonq/.next`)
- Source: Generated by `next build`
- Committed: No
